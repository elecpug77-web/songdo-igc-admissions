    1. 학과 — 학부 전공 8개 중 문과 계열 6개

    • 별도 경영학과(Business)는 없음

    • 대학원: 커뮤니케이션 석사

    2. 학과별 자세히

    심리학과 (BS)

    • 5개 핵심 분야: 발달, 사회, 임상, 인지, 행동·신경과학 → 그중 4개 분야에서 1과목씩 들음
    • 심리학 41학점 이상 (상위 과목 25학점) · 필수: 심리학개론(PSY1010), PSY2010, 통계(PSY3000), 연구방법(PSY3010) · 관련 과목 12학점
    • 연구, 또래 상담, 조교, 인턴십으로 최대 6학점 인정
    • 진로: 교육·복지, 인사(HR), 산업심리, 정부, 경영 → 대학원 가면 임상심리사·상담사·치료사
    • 부전공 / 인간공학(Human Factors) 자격과정
    • (참고) 홈페이지 요건이 2022-23 학년도 기준이라 바뀌었을 수 있음

    커뮤니케이션학과 (BA / BS)

    • 세부 전공 (졸업증명서에 표기됨):
      • 전략커뮤니케이션 (PR, 광고, 통합 마케팅)
      • 저널리즘 (디지털, 방송, 신문)
      • 커뮤니케이션 연구
      • (소개 페이지에만) 과학·보건·환경·위기 커뮤니케이션 → 상담 시 확인
    • 진로: 편집자, 홍보(PR), 마케팅, 방송·기자, 정부·비영리 기관, 로스쿨·대학원
    • 대학원(커뮤니케이션 석사)도 송도에 있음

    영화·미디어학과 (BA)

    • 세부 분야 (소개 페이지 기준): 애니메이션, 엔터테인먼트 아트·공학, 영화 제작, 미디어아트 제작
    • 다큐멘터리, 극영화, 실험영화, 시나리오, 사운드, 비평, 뉴미디어를 자유롭게 조합
    • 제작·기술 + 영화사·비평·이론
    • 부산국제영화제 참여 기회, 솔트레이크 제작 시설, 이탈리아 해외연수 선택
    • 진로: 프로듀서, 촬영감독, 편집자, 그래픽디자이너, 미디어 마케팅, 애니메이터, 게임 개발 / 법·경영·영화 대학원

    도시생태학과 (BS)

    • 도시계획, 현장 조사, 경제, 법, 사회정의 · 선택: 그린 인프라, 지속가능 개발, 지역사회 리더십, 문학 속 도시
    • 4학년: 생태계획 워크숍 + 인턴십
    • 도시·광역계획 프로그램 소속 · 4+1 (학·석사 연계) 과정 있음
    • 진로: 환경·지속가능성 계획, 공중보건, 공공정책, 지역개발, GIS 분석가, 도시계획 컨설턴트 / 건축·법·도시설계 대학원

    3. 미국 솔트레이크시티 본교 (모든 학과 필수)

    • 풀타임 최소 2학기 (전공에 따라 4학기인 경우도 있다고 FAQ에 나옴 → 지원 학과는 확인)
    • 보통 3학년 무렵, 많은 학생이 마지막 2~3학기를 본교에서 보냄
    • 송도에서 90학점이 되면 반드시 이동 (72학점에서 이동 상담 필수)
    • 설명회, 이동 의향서, 이동 신청서, 출국 전 오리엔테이션 · F-1 학생비자 필요

    4. 문과 지원자 입장에서 본 입시 요점

    항목내용
    문과라서 생기는 제한없음 — 학과별 추가 조건 없음 (학과는 입학 후 정해도 됨)
    지원 자격고교 졸업예정자 · ❌ 국내 검정고시 불가
    영어 기준 ⚠️수능 영어 인정 안 됨 → TOEFL 80 / IELTS 6.5 / TOEIC 695 / Duolingo 110 / SAT EBRW 510 / ACT English 18
    필수 서류온라인 지원서 (UAC 또는 Common App, $65) · 고교 성적표 사본 이메일 (원본은 합격 후) · 영어 성적
    선택SAT/ACT · 장학금(New Horizon) 에세이 2편
    일정우선 마감 지남 / 최종 마감 2027.01.15 · 개강 2027.02.22
    수업료연 US$20,000

    💡 문과 관점 판단 (수능 영어 1등급 · 2027 봄학기)

    • ✅ 문과 학과가 다양함 → 심리, 커뮤니케이션(PR·광고·저널리즘), 영화·미디어 쪽은 네 학교 중 여기에만 있음
    • ✅ 입학시험·추천서·자기소개서 필수 아님, 성적표 사본으로 지원 가능
    • ⚠️ 수능 영어 1등급을 쓸 수 없음 → 1/15 전에 TOEIC 695나 Duolingo 110을 따로 받아야 함 (Duolingo가 가장 빠름)
    • ⚠️ 마감이 1/15로 비교적 이름
    • 학과 고르는 팁:
      • 사람·마음에 관심 → 심리학
      • 홍보·광고·기자·방송 → 커뮤니케이션
      • 영상 제작·콘텐츠 → 영화·미디어
      • 도시·환경 정책, 공공 분야 → 도시생태

    ✅ 체크리스트

    • 학과 후보 정하기: 심리 / 커뮤니케이션 / 영화·미디어 / 도시생태 / (확인 필요) 회계·정보시스템
    • 영어 성적 확보: Duolingo 110 또는 TOEIC 695 (수능 안 됨)
    • 온라인 지원서 + $65
    • (장학금) New Horizon 에세이 2편
    • 영문 고교 성적표 사본 이메일
    • 영어 성적 공식 전송
    • 2027.01.15 전에 모든 서류 제출

    ❓ 입학처에 확인할 사항

    • 회계(BS)·정보시스템(BS): 11/21 정리 때 없던 학과가 목록에 생김 → 2027 봄학기에도 뽑는지, 커리큘럼은 어떤지
    • 솔트레이크 본교 기간: FAQ에 "전공에 따라 2학기 또는 4학기"라고만 나옴 → 지원할 학과는 몇 학기인지
    • 커뮤니케이션 세부 전공: 소개 페이지에만 있는 "과학·보건·환경·위기 커뮤니케이션"이 실제로 있는지
    • 심리학 졸업 요건: 홈페이지가 2022-23 학년도 기준 → 2027 입학생 기준으로 바뀌었는지
    • 영어 성적: 수능 영어가 정말 안 되는지 다시 확인 + Duolingo·TOEIC 성적이 1/15 마감에 맞게 반영되는지

    안내

    • 각 대학 공식 입학 홈페이지를 보고 정리한 개인 학습용 정보 페이지입니다 (이공계 2026-11-21, 문과 2026-11-26 정리). 로그인, 주문, 결제 기능은 없습니다.
    • 입시 일정과 요건은 바뀔 수 있으니 지원 전에 반드시 각 대학 공식 홈페이지에서 다시 확인하세요.
